# @yxg/mqtt 集成

帮助使用者在现有项目正确接入、升级和排查 `@yxg/mqtt`，并验证结果。分析请求只做分析；实施请求完成已授权的最小改动。保留已有业务接口、架构和工作区改动，不因接入重写通信层。

本文以 `0.1.0` 系列经验为线索，不能作为第二份 API 文档。同一版本号可能对应旧归档和未发布新构建；精确签名、能力与修复状态以目标实际制品的 exports、声明、实现及对应文档为准。

## 先定位项目和制品

- 读取目标 AGENTS.md、依赖清单／锁文件、框架与构建入口。追踪现有 MQTT/HTTP 入口、登录退出、设备路由、页面订阅、网络与前后台的真实调用链；只读实际相关文件，避免全仓倾倒和暴露凭据。
- 从已安装包、项目 vendor 归档或用户提供来源确认制品；维护者源码仅供对照，不能证明宿主已获得新能力。已有交付包括私有 tgz；可使用有权访问的 `wxfengg/yxg-mqtt` Release 或维护者归档，不假定公共 registry 可用，不猜测本机路径。
- 核对 package.json、声明的 exports 目标、实际引擎引用链、锁文件来源与制品 SHA-256；有可信交付记录时比对指纹，并检查本次需要的能力确实存在。获准安装指定库时沿用原包管理器和既有 vendor 方式；不擅自升级依赖、框架、原生插件或构建工具。
- 核对依赖库自己解析的 mqtt 是否为声明版本。目标可能另有旧 mqtt，不粗暴升级或删除它。宿主不需要为了接入再直接安装 mqtt，也不应升级宿主 Vite 来“对齐库 Vite”。
- 凭据取自项目现有登录／配置提供者，不能复制 Demo App.vue、输出完整连接对象、把 token 写入文档或技能。前端构建 env 不是保密保险箱；沿用项目认证体系。

## 选择接入路径

先读 [公共合同与最小接线](references/api-contract.md)，再只读目标平台的参考：

| 目标 | 路径与必读参考 |
| --- | --- |
| 原生微信小程序、uni-app MP-WEIXIN | `@yxg/mqtt/weixin` → [微信](references/weixin.md) |
| 浏览器、Vue/React/H5 | `@yxg/mqtt/browser` → [网页](references/browser.md) |
| uni-app APP、原生 Android/iOS、嵌入式 WebView | 先辨认真实 JS 运行环境与桥能力 → [App](references/app.md) |
| 已有可验证的独占 MQTT 引擎 | 根入口 createSession 或 /native；读 [App 的桥合同](references/app.md) |

沿用已有管理路径，同一资源不叠加所有者：

- 一个连接／已有稳定 facade：平台工厂 + MqttSession；多连接需要时使用 SessionManager。
- 需要统一设备路由或 MQTT/HTTP 调度：可选 `/communication`，再读 [设备协调器](references/communication.md)。没有此需求就不强制引入。
- 不支持的平台或缺少原生桥：继续完成能独立验证的配置、路由和生命周期工作，明确缺口；不能用空桥、假的 ACK 或“所有 App 都有 WebSocket”冒充完成。

## 落实接线

1. 在现有服务／Handler／Store 边界映射配置与协议，不编造 Topic、身份、HTTP 接口、QoS、retain、ACL 或设备 ACK。先接登录代次和清理，再接订阅、消息与发送。
2. 明确连接、重连、订阅和待发意图各自的唯一所有者，避免同 clientId 双连接或重复队列。保留同步 facade 语义；本地接纳与业务成功分开，不吞错返回成功，不自动补发已提交／结果未知的命令。
3. 排障按“网络提示 → 引擎加载 → 连接 → 当前订阅确认 → 业务补查 → 新回复”逐层取证。应用补查、Store 和业务周期属于宿主；未定位问题列为取证缺口，不把一次事故写成通用根因。
4. 旧 workaround 只在目标制品与环境仍命中时保留；确认库已覆盖后，在授权范围内撤除重复适配并回归。不要强制新协调器、自动重试、双队列或构建插件。
5. 按 [分层验收](references/validation.md) 选择与改动相关的最小检查。设备控制命令仅在明确授权的安全测试条件下验证。

## 交付标准

依 [验收与交付](references/validation.md) 说明实际改动、制品／能力、验证证据和未覆盖范围；优先更新已有项目文档，具体事故留在项目记录。不自行提交、发布或部署，不新增重复报告或踩坑技能。
