# 接入验证与交付

按本次改动选择检查，保持已有测试框架和构建工具；不因验证安装新依赖，不为纯文档变动构建宿主。旧制品缺少能力时记录限制，不能把能力检查改成依赖升级。

## 证据分层

每项结论关联制品来源／指纹、实际宿主输出、环境及场景；“未执行”“模拟通过”“用户报告”单独标注，不能相互代替。

| 证据 | 可支持的范围与限制 |
| --- | --- |
| 静态源码／类型／构建 | 接线和打包检查；不能证明运行时恢复或设备成功 |
| 单元测试／模拟 SocketTask | 已覆盖的状态机与竞态；不证明微信真实网络栈 |
| 完整引擎模拟／本地协议对端 | 对应引擎求值或协议交互；本地对端不是完整云 Broker，无云 TLS／ACL／设备证据 |
| 微信开发者工具／预览统计 | 对应产物和工具环境、打包口径；不代表真机或所有基础库 |
| 真实 Broker／TLS／设备回包 | 仅覆盖已测身份、链路与业务消息，PUBACK 仍不等于设备 ACK |
| 真机实测／用户报告 | 分别记录设备、系统、宿主和场景；报告不冒充本轮亲自执行，不外推全部机型 |

## 本地接入检查

- 核对归档／安装包、锁文件来源与可信指纹；检查声明的公开入口及本次使用能力，不依赖相同版本号。核对宿主实际解析到的库与 mqtt 引擎，避免用开发树替代安装制品。
- 用项目已有类型检查／最小构建验证变动接线；不以 skipLibCheck／any 掩盖新合同问题。业务不 import 私有 src／hash chunk，源码示例不是包内导出。
- 验证拥有者、同步 facade、ticket.done 与错误 evidence；onDelivery／done 不重复提示，日志不含凭据或完整 cause。公共行为见[API 合同](api-contract.md)，协调器差异见[communication](communication.md)。

若本次是在库维护环境核验制品，可按实际源码脚本使用 `npm test`、`npm run verify:release -- /path/package.tgz`。当前前者含构建前置步骤；后者含隔离解包、NodeNext/Bundler 类型、Vite 构建、微信探针、Chrome WebSocket 与本地协议测试，依赖已有 Chrome／TypeScript（可用 CHROME_PATH/TSC_PATH 指定）。这是可用工具线索，不是消费项目必须运行的流程；脚本与制品须匹配，禁止在只读取证任务中触发构建，也不假设脚本随包分发。

## 按改动选择恢复场景

优先用现有测试／可控模拟覆盖相关竞态，再补实际平台证据；不要为每次小改动强制跑完整矩阵。模拟必须观察真实公开行为，不能把假 ACK 当外部验收。

| 触发范围 | 场景与可观察结果 |
| --- | --- |
| 初始化／登录切换 | 并发启动、工厂晚到成功／失败、退出和换账号；迟到实例清理，旧失败不销毁新会话，无旧 Store 写入或新重连 |
| 订阅首次／重连 | 首次和重连 SUBACK 拒绝、调用超时、Topic 修正、显式重试；按实际合同处理旧句柄，无忙循环、重复监听或旧 guard 复活 |
| 共享 Topic／首帧 | 新 handle 复用既有确认也能 ready；同帧 SUBACK 后、ready.then 前的消息按有效 scope 接收，不丢首条 |
| 后台恢复／网络 | 后台漏网络事件、前台补采样、乱序旧快照、hide 后迟到、快速 hide/show 与未结束 disconnect；最终按最新意图恢复，当前 SUBACK 后收到新消息 |
| 容量与出队 | outbox 禁用、数量／字节暂满、单条超限、订阅门禁；暂满不被宿主提前出队丢弃，永久超限不无限等待，唤醒前复查授权／路由／有效期 |
| 容量竞态／共享资源 | 释放先于拒绝处理、wait-only／done 已结束但槽位未释放、迟到 ACK／退役释放、同步预留与策略缩限；不把本地等待结束当可用容量，不因某设备门禁阻塞无关设备 |
| 已接纳／结果未知 | accepted 后超时或取消，submitted-unknown 保持未知；不触发业务自动补发、跨通道或跨会话搬运，库协议层既有 QoS1 恢复按实际合同检查 |
| 页面／业务异步 | 卸载或新操作先完成，旧元数据／提示晚到；不覆盖新停止／暂停、不向失效页面提示，页面仅释放自身资源 |

## 平台条件检查

- **微信加载／分包变动**：检查开发和发行真实产物、桥引用链、当前 module ID、环境初始化后才求值、实际分包注册与下载。包大小采用获准执行的微信预览／上传统计，不能只看文件大小；未获准或未执行就标明缺口。
- **微信加载恢复变动**：首次下载失败、超时／取消、迟到成功／拒绝、退出／后台撤销；Session 尚不存在时不能靠 connect 重试，逻辑超时不承诺物理下载取消。
- **微信兼容适配变动**：完整目标引擎的普通环境、标准方法 getter、真实 accessor 及局部 navigator；升级后检查补丁是否重复并验证退役后的宿主输出。Node import 或模拟成功不替代工具和真机。具体方法见[微信参考](weixin.md)。
- **浏览器／WebView**：客户端而非 SSR 创建，真实 WebSocket、CSP／WSS／Origin，以及页面卸载／热更新后的资源释放。
- **原生桥**：真实 ACK、connection epoch、独占实例、SDK 自动重连所有权和 retire/destroy；缺桥不得编造实测。参见[桥合同](app.md#桥接合同)。

## 外部环境最小动作

只使用授权测试身份、回环或确定无副作用的业务查询；控制、复位、解绑等命令需明确安全测试授权。

1. 在目标环境首次加载、连接、SUBACK、安全发送并收到新消息，记录制品及工具／设备版本。
2. 断网恢复、前后台／锁屏后检查当前订阅确认及新回包；反复进入页面不增加共享连接，退出／换账号无旧身份回调或重连。
3. 有专用测试权限时检查认证／订阅拒绝，不修改生产 ACL 或试错真实账号。无法命中 unknown 等窗口时如实标注未覆盖。

不能控制手机动作时，只给本次相关的具体短步骤，不反复要求重测已确认的同制品同环境证据。没有实际服务配置时完成可独立验证的接线，说明实网缺口；历史测试数量或旧真机成功不能继承到新构建。

## 输出

说明改动文件与调用点、依赖／锁变化、制品指纹与所用能力、平台／所有者选择、后台和 unknown 策略、workaround 保留或退役依据、实际验证及未执行原因。维护源、制品或环境改变后，原兼容与验收结论须重新评估。

优先更新已有集成文档，具体事故、设备协议、消息 ID、品牌策略和业务周期留在项目记录；未定位的无回包问题保留取证缺口。保留必要的原制品／锁信息供回退。停止自己启动的临时服务并说明，不接管用户原有服务；不自行提交、推送、发布或部署。
